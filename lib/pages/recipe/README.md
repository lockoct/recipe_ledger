# 菜谱模块 (Recipe Module)

## 模块介绍

菜谱模块是菜谱账本应用的核心功能模块，用于创建、编辑和管理菜谱。该模块支持菜谱封面上传、原材料管理、富文本编辑（做法步骤和注意事项）等功能，为用户提供完整的菜谱管理体验。

## 页面结构

### 1. RecipeGridPage（菜谱网格页）
- **功能**：展示菜谱网格布局，支持搜索和添加新菜谱
- **入口**：底部导航栏"菜谱"标签

### 2. RecipeEditPage（菜谱编辑页）
- **功能**：创建或编辑菜谱，包含封面上传、原材料管理、富文本编辑
- **入口**：点击浮动添加按钮或编辑菜谱

## 功能特性

### RecipeGridPage
- 🔍 **搜索功能**：支持按菜谱名称搜索
- 📐 **网格布局**：2列卡片网格展示
- ➕ **添加按钮**：浮动按钮添加新菜谱
- 📱 **卡片设计**：包含封面图和菜谱名称

### RecipeEditPage
- 🖼️ **封面上传**：支持从相册选择封面图片
- ✏️ **菜谱名称**：输入菜谱名称
- 📦 **原材料管理**：添加、编辑、删除原材料（支持菜品选择或自定义）
- 📝 **富文本编辑**：做法步骤和注意事项支持格式化编辑
- 🖼️ **图片插入**：富文本编辑器支持插入图片
- 💾 **保存功能**：保存菜谱到本地存储

## 操作流程

### 浏览菜谱列表
1. 进入"菜谱"标签页
2. 查看菜谱网格列表
3. 使用搜索框搜索特定菜谱
4. 点击菜谱卡片查看详情（待开发）
5. 点击浮动按钮添加新菜谱

### 创建新菜谱
1. 点击浮动添加按钮进入编辑页面
2. 点击封面区域上传封面图片（可选）
3. 输入菜谱名称
4. 点击"添加"按钮添加原材料
   - 选择"菜品"模式：从菜品列表中选择并设置用量
   - 选择"其他"模式：输入自定义原材料名称和用量
5. 在"做法步骤"编辑器中输入烹饪步骤
6. 在"注意事项"编辑器中输入注意事项（可选）
7. 点击"提交"保存菜谱

### 编辑菜谱
1. 在菜谱列表中选择要编辑的菜谱（待实现）
2. 修改菜谱信息
3. 点击"提交"保存修改

## 技术细节

### 状态管理
- 使用 `RecipeProvider` 管理菜谱数据
- 使用 `DishProvider` 获取菜品数据用于原材料选择

### 数据模型
- **Recipe**：菜谱模型，包含 id、name、coverImage、ingredients、instructions、notes 等字段
- **RecipeIngredient**：原材料模型，支持菜品关联或自定义名称

### 核心组件
- **AddIngredientDialog**：原材料添加/编辑弹窗组件
- **QuillEditor**：富文本编辑器（flutter_quill）
- **QuillSimpleToolbar**：富文本工具栏
- **FlutterQuillEmbeds**：图片嵌入支持

### 关键技术点
1. **富文本编辑器**：使用 `flutter_quill` 实现，支持格式化和图片插入
2. **图片插入**：集成 `flutter_quill_extensions` 支持图片渲染
3. **键盘感知滚动**：监听键盘弹出，自动滚动到聚焦的编辑器
4. **焦点管理**：多个编辑器之间切换时正确关联工具栏
5. **原材料弹窗**：独立封装为 `AddIngredientDialog` 组件，支持菜品/其他模式切换
6. **表单验证**：确保菜谱名称和原材料必填项验证
