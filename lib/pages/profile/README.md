# 个人中心模块 (Profile Module)

## 模块介绍

个人中心模块是菜谱账本应用的用户中心，提供用户信息展示和应用设置入口。该模块包含用户信息卡片、功能列表（单位切换、初始化数据、关于、帮助）等功能。

## 页面结构

### ProfilePage（个人中心页）
- **功能**：展示用户信息和功能入口列表
- **入口**：底部导航栏"我的"标签

## 功能特性

### ProfilePage
- 👤 **用户信息卡片**：展示用户头像和欢迎信息
- 🔧 **单位切换**：进入价格单位设置页面
- 🔄 **初始化数据**：清空并重新生成模拟数据（开发调试用）
- ℹ️ **关于**：显示应用版本和介绍信息
- ❓ **帮助**：显示使用帮助说明

## 操作流程

### 进入个人中心
1. 点击底部导航栏"我的"标签
2. 查看用户信息卡片
3. 选择功能列表中的选项

### 使用各项功能
1. **单位切换**：点击进入 UnitSwitchPage 选择价格单位
2. **初始化数据**：点击后确认对话框，执行数据初始化
3. **关于**：点击查看应用版本和介绍
4. **帮助**：点击查看使用说明

## 技术细节

### 状态管理
- 使用 `AppProvider` 管理应用全局设置

### 核心组件
- **ListTile**：功能列表项组件
- **AlertDialog**：确认对话框和信息展示

### 关键技术点
1. **渐变背景**：顶部主题色渐变到底部灰色背景
2. **状态栏融合**：用户信息卡片与状态栏融为一体
3. **对话框状态管理**：初始化数据对话框使用 StatefulBuilder 管理异步状态
4. **数据初始化服务**：调用 `DataInitializationService` 执行数据重置
