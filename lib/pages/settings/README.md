# 设置模块 (Settings Module)

## 模块介绍

设置模块是菜谱账本应用的配置中心，提供应用设置和偏好配置功能。当前主要包含价格单位切换功能，后续可扩展更多设置选项。

## 页面结构

### UnitSwitchPage（单位切换页）
- **功能**：切换价格显示单位
- **入口**：个人中心 -> 单位切换

## 功能特性

### UnitSwitchPage
- 📐 **单位选择**：支持元/斤、元/公斤等单位切换
- 💾 **自动保存**：切换后自动保存到用户设置

## 操作流程

### 切换价格单位
1. 从个人中心进入"单位切换"页面
2. 查看当前选中的单位
3. 点击其他单位选项进行切换
4. 系统自动保存并提示切换成功

## 技术细节

### 状态管理
- 使用 `AppProvider` 管理用户设置
- 通过 `updatePriceUnit` 方法更新单位配置

### 数据模型
- **UserSettings**：用户设置模型，包含 priceUnit 字段

### 单位常量
- 在 `AppConstants` 中定义价格单位常量：
  - `PriceUnits.yuanPerJin`：元/斤（默认）
  - `PriceUnits.yuanPerKg`：元/公斤

### 关键技术点
1. **单位转换**：通过 `UnitConverter` 工具类进行价格单位转换
2. **全局生效**：切换单位后，所有价格显示自动更新
3. **本地持久化**：用户设置自动保存到本地存储（Hive）
