# 菜品模块 (Dish Module)

## 模块介绍

菜品模块是菜谱账本应用的核心模块之一，主要用于管理和展示菜品信息及其价格趋势。该模块提供菜品列表浏览、菜品详情查看、价格趋势图表展示等功能，帮助用户了解菜品价格变化情况。

## 页面结构

### 1. DishListPage（菜品列表页）
- **功能**：展示菜品列表，支持搜索和分类筛选
- **入口**：底部导航栏"菜品"标签

### 2. DishDetailPage（菜品详情页）
- **功能**：展示菜品详细信息和价格趋势图表
- **入口**：点击菜品列表中的任意菜品卡片

## 功能特性

### DishListPage
- 🔍 **搜索功能**：支持按菜品名称搜索
- 🏷️ **分类筛选**：支持按菜品分类筛选
- 📋 **菜品列表展示**：展示菜品名称、价格、同环比变化
- 📱 **卡片布局**：横向卡片，包含图标、名称、价格、同环比信息

### DishDetailPage
- 🖼️ **图片轮播**：菜品图片展示（模拟数据）
- 💰 **价格显示**：支持多单位切换显示
- 📊 **价格趋势图表**：展示指定日期范围内的价格走势
- 📅 **日期选择**：支持自定义日期范围查看趋势

## 操作流程

### 浏览菜品列表
1. 进入"菜品"标签页
2. 查看菜品列表，可使用搜索框搜索特定菜品
3. 点击分类筛选栏展开/收起分类选项
4. 选择分类进行筛选
5. 点击菜品卡片进入详情页

### 查看菜品详情
1. 在菜品列表中点击任意菜品卡片
2. 查看菜品名称、价格、城市、分类信息
3. 滑动图片轮播查看菜品图片
4. 点击日期选择器调整日期范围
5. 查看价格趋势图表

## 技术细节

### 状态管理
- 使用 `DishProvider` 管理菜品数据
- 通过 `Provider.of` 和 `Consumer` 进行状态监听和更新

### 数据模型
- **Dish**：菜品模型，包含 id、name、price、city、category、updateTime 等字段
- **PriceRecord**：价格记录模型，用于价格趋势图表

### 核心组件
- **DishSearchBar**：搜索栏组件
- **CategoryFilterBar**：分类筛选栏组件
- **CategoryFilterOverlay**：分类筛选覆盖层组件
- **PriceDisplay**：价格显示组件
- **PriceTrendChart**：价格趋势图表组件
- **CarouselSlider**：图片轮播组件（第三方库）

### 关键技术点
1. **搜索过滤**：通过 `setSearchQuery` 更新搜索词，实时过滤菜品列表
2. **分类筛选**：支持展开/收起的分类选择界面
3. **状态保持**：使用 `IndexedStack` 保持页面状态
4. **单位切换**：通过 `AppProvider` 监听单位变化，自动转换价格显示
5. **图表绑定**：日期范围变化时自动更新图表数据
