# 菜谱账本应用技术方案

## 1. 项目概述

本项目是一个基于Flutter开发的菜谱账本应用，主要功能包括菜品单价查询、自定义菜谱管理、富文本做法编辑以及离线数据支持。应用支持多单位切换显示，并具备城市切换功能。

## 2. 技术栈

### 核心技术
- **Flutter**: 跨平台移动应用开发框架
- **Dart**: 开发语言
- **Provider**: 状态管理
- **Hive**: 本地数据存储（用于离线使用）
- **Dio**: 网络请求（后续对接后端）
- **flutter_quill**: 富文本编辑器

### 依赖库
- `provider`: 状态管理
- `hive`: 本地数据库
- `hive_flutter`: Hive的Flutter集成
- `dio`: 网络请求
- `flutter_quill`: 富文本编辑器
- `intl`: 国际化和日期格式化
- `shared_preferences`: 存储用户设置

## 3. 功能模块

### 3.1 菜品单价列表
- 显示菜品名称、单价、单位
- 支持按城市切换（暂时只支持广州市）
- 支持按菜品名称搜索
- 支持按单价排序

### 3.2 自定义菜谱管理
- 添加新菜谱（名称、封面图）
- 编辑菜谱详情
- 删除菜谱
- 查看菜谱列表

### 3.3 菜谱详情
- 关联菜品及用量管理
- 富文本形式的做法编辑
- 自动计算菜谱成本
- 保存/分享菜谱

### 3.4 单位设置
- 默认单位：元/斤
- 可切换单位：元/斤、元/公斤（千克）、元/两
- 单位切换后全局生效

### 3.5 离线功能
- 应用启动时从服务器获取最新数据
- 数据缓存到本地
- 无网络时使用本地缓存数据
- 网络恢复后自动同步

## 6. 数据流设计

### 6.1 离线数据处理
1. 应用启动时检查网络连接
2. 有网络：从服务器获取最新数据并更新本地缓存
3. 无网络：直接使用本地缓存数据
4. 数据变更时：先更新本地缓存，网络恢复后同步到服务器

### 6.2 单位转换逻辑
- 内部存储统一使用元/斤
- 显示时根据用户设置进行单位转换
- 输入时根据当前单位进行转换后存储
